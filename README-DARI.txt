اپلیکیشن حاضری شرکت احسان شیرزی

این پروژه یک پوسته اندروید (WebView) برای نسخه آنلاین سیستم حاضری است.
برنامه صفحه HTTPS زیر را باز می‌کند:
https://companybahrami-star.github.io/Ehsan-Shirzi-Attendance-/

مهم:
1) پیش از ساخت APK، مطمئن شوید سایت GitHub Pages باز می‌شود و فایل index.html نسخه نهایی در آن قرار دارد.
2) دوربین در اولین استفاده اجازه می‌خواهد.
3) نسخه فعلی HTML اطلاعات را فقط در حافظه همان مرورگر/دستگاه ذخیره می‌کند؛ این APK به‌تنهایی دیتابیس مشترک آنلاین ایجاد نمی‌کند.
4) برای ذخیره مرکزی بین چند موبایل، باید Firebase یا سرور امن به پروژه وصل شود.
5) QR فعلی بر اساس شماره کارمند ساخته می‌شود و به‌تنهایی احراز هویت قوی نیست.

ساخت APK با GitHub Actions:
- تمام محتویات این پوشه را در ریشه یک مخزن GitHub آپلود کنید.
- به تب Actions بروید.
- workflow با نام Build Ehsan Shirzi Attendance APK اجرا می‌شود.
- پس از سبز شدن، از بخش Artifacts فایل APK را دانلود کنید.
